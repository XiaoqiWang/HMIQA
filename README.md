# HM-IQA: Human–Machine Image Quality Assessment

Official repository for **“Bridging the Human-Machine Perception Gap: A Unified Representation Learning Model for Image Quality Assessment”** by Xiaoqi Wang, Yun Zhang, and Patrick Le Callet.

HM-IQA jointly assesses human perceptual quality and machine task utility in degraded images. The code and pretrained models are currently being organized and will be released here when ready.
